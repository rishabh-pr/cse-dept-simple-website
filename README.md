# CSE Department Website (Simple Version)

A basic multi-page website for a college CSE department, made with plain HTML, CSS and JavaScript. No frameworks, no build tools - just open the files in a browser.

## Pages
- `index.html` - Home page with department info
- `faculty.html` - Table of faculty members
- `programs.html` - Programs offered and subjects
- `timetable.html` - Weekly class timetable
- `achievements.html` - List of achievements and a papers-published table
- `gallery.html` - Photo gallery (click a thumbnail to see it bigger) + sample video/audio
- `contact.html` - Contact form with simple JavaScript validation

## Folders
- `css/style.css` - all the styling (flexbox is used only for the top navigation bar)
- `js/script.js` - all the JavaScript (image gallery and form validation)
- `images/` - placeholder pictures used on the site

## How to run it
Just double-click `index.html` to open it in your browser. No installation needed.

## How to put it on GitHub Pages
1. Create a new GitHub repository and push all these files to the `main` branch.
2. Go to your repository **Settings > Pages**.
3. Under "Source" choose the `main` branch and `/ (root)` folder, then Save.
4. Your site will go live at `https://<your-username>.github.io/<repo-name>/`

## Notes
- The contact form does not actually send an email, it only checks the fields with JavaScript and shows a message on the page.
- All images are simple placeholder pictures - you can replace them with real photos, just keep the same file names.
